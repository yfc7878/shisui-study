# 拾穗 Study 使用说明

写给第一次打开这个应用的你。按顺序做完「第一次设置」，之后每天只需要用「错题」「English」「待审阅」三个入口。

---

## 一、第一次设置（5 分钟）

### 1. 登录

- 地址：本地 `http://localhost:8787`，或你部署的域名。
- 密码来自部署时 `.env` 的 `ADMIN_PASSWORD`；如果没有设置，首次启动会在服务器日志中生成并显示一次随机密码。
- 勾选「在这台设备上保持登录」，30 天内不需要重复登录。

### 2. 修改密码

右上角齿轮 → 设置 → 账号 → 修改访问密码。

### 3. 配置 DeepSeek API

设置 → AI 与提示词：

1. 打开 [platform.deepseek.com](https://platform.deepseek.com/) 创建 API Key；
2. 填到「API Key」；
3. Base URL 保持 `https://api.deepseek.com`；
4. 文本模型 / 视觉模型均填 `deepseek-flash`；
5. 点击「测试连接」，看到「连接成功」后保存。

Key 只保存在这个浏览器。换手机或电脑使用时，需要在每台设备各填一次；学习数据本身会自动同步。

### 4. 可选：加载示例

如果数据库为空，可以在服务器运行 `npm run seed` 查看示例错题、佳句和词汇。示例可以在回收站删除。

## 二、错题集

### 2.1 收一道错题

1. 点击左侧「错题本」→ 右上角「收一道错题」。
2. 上传图片：
   - 点击虚线区域选择，或直接拖拽；
   - 支持一次 1–12 张；
   - 同一道题的多页、多张照片可以一起传，AI 会合并。
3. 逐张裁剪（可选但推荐）：
   - 点击缩略图打开裁剪器；
   - 拖动空白处画选框，拖动四角调整；
   - 「全图」恢复整张，「不裁剪，用原图」跳过；
   - 用「使用」开关决定这张图是否参与识别；
   - 上下箭头调整顺序。
4. 右侧可选设置：
   - **科目提示**：帮 AI 判断科目；
   - **深度思考模式**：难题、压轴题建议开启；简单题关闭更快更省；
   - **额外提示词**：例如「重点解释第二问」「答案保留根号」。
5. 点击「开始 AI 识别」，等待 30 秒–3 分钟。
6. 识别完成后会跳转到「待审阅」。**AI 不会直接入库**，这是有意的设计。

### 2.2 在待审阅里确认

错题编辑器从上到下：

1. **题目档案**：科目、来源、章节、错因、难度、知识点、标签。推荐补全来源与错因，导出时会用到。
2. **题目**：Markdown + LaTeX 题干；可「编辑 / 预览」切换。
3. **题目配图**：
   - 若 AI 标记了图中图形，点「按 AI 标记裁剪」自动生成；
   - 也可以「手动裁剪配图」，从原图框选；
   - 配图可改图注、排序、删除；
   - 导出 Word 时配图会随题目排版。
4. **AI 参考函数图像**：如果题目涉及函数，AI 会给出绘图表达式，页面自动生成小图；它只用于辅助理解，不是原题配图。
5. **答案与解析**：同样支持 Markdown/LaTeX 预览。
6. **通过并归档**：确认后进入错题本。
7. 若 AI 答错：点「AI 重来」，可选择是否打开深度思考，再写补充要求；重做会覆盖当前答案/解析，但仍需你确认。
8. 不想保留：移入回收站。

> 多条题目：一张试卷照片里有几道独立题时，AI 会拆成多条，每条单独审阅。

### 2.3 错题本

- 顶部切换「已收录 / 待审阅 / 全部」；
- 按科目、难度筛选，按题干/来源/标签搜索；
- 卡片右上角复选框支持批量：批量通过、导出所选、移入回收站；
- 点击卡片进入详情，可编辑、AI 重来、导出、回收；
- 「全部」不包含回收站内容。

### 2.4 重做建议

导出时选择「留出重作空间」，打印后先只看题干重做，再对照答案解析。错题本的价值在重做，不在收藏。

## 三、English

### 3.1 收集佳句

1. English → 佳句 → 「收集佳句」。
2. 选择方式：
   - **主题生成**：输入主题（如「环境描写」「科技与生活」），选择 3–10 条；
   - **文本提取**：粘贴一段英文（作文、外刊、阅读），AI 提取佳句；
   - **图片提取**：上传 1–6 张图片（作文、笔记），AI 识别英文句子。
3. 可选「深度思考模式」和额外要求。
4. 生成后进入待审阅。逐条检查：
   - **主题**：分类用（环境描写 / 观点表达 / 过渡衔接 / 高级替换……）；
   - **内容概要**：这句话讲什么、适合放在作文哪里（和主题是两个字段）；
   - **用法与句型**：为什么值得学；
   - **新例句**：AI 举一反三；
   - 可改、可复制、可 AI 重来。
5. 通过后进入佳句库。

### 3.2 佳句库

- 搜索内容/翻译/主题；
- 主题筛选、排序；
- 多选批量通过（待审阅）或移入回收站；
- 点击卡片查看详情、编辑、复制英文、AI 重来；
- 「导出 Word」进入排版页。

### 3.3 单词 / 词组解析

1. English → 单词；
2. 输入单词或词组，选主题，生成；
3. 打开词条详情（待审阅），在三种视图间切换：
   - **思维导图**：中心词 + 释义/用法/搭配/同义/反义/易混/例句/记忆法分支，可点击展开；
   - **文字行**：完整结构化内容，适合仔细阅读；
   - **编辑**：修改任意字段、增删例句/搭配/延伸、调整顺序；
4. 通过后进入词汇库，之后仍可随时编辑。

### 3.4 导出英语

- 分类方式：按主题 / 按日期 / 不分组；
- 主题顺序：用上下箭头调整；
- 篇目顺序：每条佳句也可以单独上下移动；
- 布局：卡片式 / 清单式；
- 内容开关：翻译、用法、例句、例句翻译、概要、标签、来源、引号；
- 字体、字号、行距、纸张、页边距、页码。

## 四、待审阅与回收站

- 所有 AI 结果统一进入「待审阅」：错题 / 佳句 / 词汇分栏。
- 支持全选、批量通过、批量移除。
- 通过后进入对应的收藏。
- 回收站保留删除内容，可恢复或永久删除；「清空回收站」不可撤销。
- **自动清理**：在回收站顶部设置保留天数（3–365 天），开启后服务器每 6 小时检查一次；只清理超过保留期的内容，未过期内容不受影响。
- **手动清理**：可以单选/多选永久删除，也可以「立即清理过期」；「清空回收站」会清空全部内容。永久删除时会同时清理不再被引用的题目图片。
- 自动清理默认关闭，不会未经设置删除任何内容。

## 五、Word 导出

### 错题

路径：错题本 → 导出 Word，或选中题目 → 导出所选。

可以设置：

- 标题、副标题、封面；
- 每题后跟答案 / 答案统一放卷末；
- 包含答案、解析、题目档案、配图、知识点、错因；
- 重作留白（小 / 中 / 大）；
- 按科目 / 来源 / 难度分组，或不分；
- 按收录时间 / 难度 / 科目排序；
- 宋体 / 仿宋 / 楷体 / 微软雅黑 / 黑体；
- 正文字号、标题字号、行距；
- A4 / B5，标准 / 窄 / 宽边距；
- 页码、题目编号、页眉水印。

### 英语

路径：English → 导出 Word。

- 主题分组、主题顺序、篇目顺序；
- 卡片式 / 清单式；
- 翻译、用法、例句、例句翻译、概要、标签、来源开关；
- 字体、字号、行距、纸张、页边距、页码；
- 标题、副标题、封面。

### 公式说明

网页中用 KaTeX 原生渲染 LaTeX。Word 不支持直接渲染 LaTeX，导出时会将常见公式转为 Unicode 近似（分数、根号、希腊字母、不等号等）。需要原生 Word 公式时，请在导出后手动替换重点公式。

## 六、工具箱

### 番茄钟

- 专注 25 分钟 / 短休息 5 分钟 / 长休息 15 分钟，可自定义；
- 空格开始/暂停；
- 完成时提示音；
- 专注记录会进入总览页统计；
- 支持自动开始下一段（默认关闭）。

### 高级计算器

- 支持 `+ - * / ^ ! %`、括号、`sin cos tan asin acos atan`、`log ln lg sqrt cbrt abs exp floor ceil round min max`、`π e`；
- DEG / RAD 切换；
- 历史记录、内存 M+ M- MR MC；
- 键盘直接输入，Enter 计算，Esc 清空。

### 函数图像

- 输入 `sin(x)`、`x^2-2x-3`、`1/x`、`sqrt(x)`、`e^x`、`ln(x)` 等；
- 最多 4 条曲线；
- 滚轮/按钮缩放，拖动平移，悬停查看坐标；
- 不连续点（如 `1/x` 在 0 处）会自动断开；
- 可导出 PNG。

## 七、数据与设备

- 所有设备访问同一个地址，登录同一密码，数据一致。
- 数据保存在服务器 `data/`，手机/电脑只是浏览器。
- 设置 → 数据 → 下载 JSON 备份（文字数据）。
- 完整备份请复制整个 `data` 目录。
- 换服务器：复制 `data` 目录过去即可。

## 八、常见问题

**AI 一直显示正在读题？**
思考模式或图片多时会慢。超过 4 分钟会超时；可关闭思考、减少图片、裁剪掉无关区域再试。

**识别出来的公式是乱码？**
AI 使用 LaTeX；如果原题手写不清，识别会出错。请在审阅页直接修改，公式用 `$...$` 包裹。

**错题里的函数图没有自动出现？**
AI 不一定每次都准确标记图像位置。审阅页「题目配图 → 手动裁剪配图」框选即可。

**能导出 PDF 吗？**
目前直接导出 Word，可在 Word/WPS 中另存为 PDF。打印效果更好。

**能多人用吗？**
不能，这是单用户项目。密码只有一个。

**密码忘了？**
服务器运行 `npm run reset-password -- 新密码`，数据不会丢。

**API Key 会同步吗？**
不会。Key 按浏览器保存，每台设备填一次。
